七道改写题有独立标注的教材依据，但当前实现依赖词项覆盖和名称规则，未得到候选。这足以支持下一步开展语义检索对照，尚未证明向量检索能够改善结果，也不支持直接选定向量库或迁移主服务。首轮优先比较词法与向量／混合检索，Python单Agent及LangGraph继续待评估。阶段四的两项教师反馈失败与本实验分开处理，不能归因为检索不足。

第八个失败S09问“导数这个术语最早出现在哪一年？”。资料无年份，期望空检索后按证据不足处理；实际在检索前返回“请明确你指的是哪个对象”。`RagFollowUpResolver`的指代模式匹配“这个术语”，当前句同时含显式对象且没有历史时进入澄清分支。控制实验仅去掉“这个”，同一实现返回无澄清、空检索，定位到指代前处理。该诊断变体不加入24题分母，不修改冻结问题，也不将失败改为通过；本轮未修复应用逻辑。

## 题集与边界

[stage5-retrieval-v1](stage5-retrieval-cases.json)在首次测量前写入固定问题、预期和评分要求。阶段一12题及自编材料从[原题集](stage1-cases.json)原样读取；新增Java材料为三段短合成文本，并非原Java教材。原Java20题没有运行，本轮不能称为阶段一32题的完整回归。新增题用于暴露已知规则边界，属于有意构造的压力样本。

`Stage5RetrievalProbe.java`使用当前编译后的`RagFollowUpResolver`，通过反射调用生产`RagServiceImpl.retrieveChunks`及引用转换，包含真实的拆分子问题、词法排序、比较回退和topK选择；未在评测器中另写一套排名算法。Mapper替身仅返回本案预先选好的合成片段，不启动Spring服务或MySQL，不访问用户资料或发送模型请求。生产方法签名变化会使探针失败，需更新适配器后重新测量。

本轮**不覆盖**上传解析和真实分片、SQL过滤与用户所有权、HTTP与事务、回答生成、引用语义／注入抵抗、超时回退、真实学习者或学习效果。S10仅检查候选范围，不能作为权限测试；C01／C02的命中不能证明模型不会执行教材夹带指令。

每题先预热3次，再采样7次，检查各次检索输出一致，以中位数记录；汇总延迟保存在机器结果中。时间只包含进程内指代与检索，语料极小，不含JVM启动、SQL、网络和模型时间，不能用于生产SLA或外部服务超时设置。费用记录仅能确认为本轮外部模型调用0次。

## 复现与验证

先确保Java17、Node和后端运行依赖可用。在仓库根目录执行：

```powershell
cd D:\AI-Tutor\backend
.\mvnw.cmd -o verify
cd D:\AI-Tutor
node --test backend/scripts/*.test.mjs
node backend/scripts/evaluate-stage5-retrieval.mjs --output-dir backend/target/stage5-retrieval-new-run
```

`backend/target/dependency`缺失时，先在backend执行`mvnw.cmd dependency:copy-dependencies -DincludeScope=runtime`。评测不读取`.env`，没有真实模型模式；`--java-bin`可指定Java可执行文件。输出目录必须不存在，拒绝覆盖。返回码0表示题集全部通过，1表示诊断完成但存在失败，2表示输入、依赖或执行错误。当前基线预期返回1。

每次输出完整题集、仅含检索输入的`input.json`、逐题结果、报告和指纹；检索进程不会收到预期答案、证据标注或rubric。保存实际参与运行的源码、脚本、原题集快照，以及编译类树与运行依赖树SHA256。源码晚于编译类时拒绝运行，先重新构建。该检查与指纹用于追溯，不代替干净检出构建。

本次原始结果位于`backend/target/stage5-retrieval-baseline-a`与`stage5-retrieval-baseline-b`，均在Git忽略目录。第二次修正了评测器偶数样本中位数统计后重跑，24题判决与第一次一致；仓库内JSON与第二次`report.json`逐字节相同。原题、材料及生产实现未在两次运行间改变。指代控制实验保存在`backend/target/stage5-resolver-diagnostic-{input,results}.json`。

新增8项工具测试先失败再通过：覆盖全部证据组分母、部分命中、空结果与澄清的区别、漏行／重复／未知结果、未知／未选／重复／超限片段、跨片段要求、对象解析和非法时间、中位数。最终脚本88项通过，后端292项无失败无跳过且构建成功。后端和前端应用源码、数据库未在本轮改动，浏览器与候选服务故障检查未执行。阶段五仍进行中。
