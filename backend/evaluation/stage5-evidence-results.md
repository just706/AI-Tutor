# 阶段五片段答案依据规则验证

日期：2026-10-30。结论：**规则能拦住已知的两处定义误召回，但未通过通用答案依据验证，不接入应用。** 新增24组问题与片段对照中，实验放行／拦截判对15组，误放行7组，误拒2组。全部失败保留在[机器结果](stage5-evidence-results.json)，不能以旧题改善替代准入结论。

## 验证了什么

此前H13询问蓝桥编码的发明者，召回的只有概念定义；H14询问本次调查的总体方差实际值，召回的也只有定义。当前候选在余弦分数达到阈值后就保留片段，RRF只融合排名，不检查所问关系及信息是否存在。这是两项误召回最早可见的缺口，不涉及模型生成回答。

本轮实现一个**离线、仅用于排除的规则原型**：识别有限句式中的人物、年份、数量属性问题，要求已召回片段中同一句出现对象与相应的表面线索；任一已识别的子问题缺少线索时清空本轮检索。检查只使用本案已选且已召回的片段，不借用其他资料，也不读预期答案。规则未覆盖的问题或找到线索的问题均返回`unverified`，从不返回`支持`或`正确`。

[实验策略](stage5-evidence-policy.json)明确：为观察拦截效果，本次对照仍放行`unverified`。这只是实验约定，不是产品默认行为，也不是语义验证通过。原型没有修改线上检索、提示、数据库或接口。

## 新增问题／片段对照

[24组固定对照](stage5-evidence-cases.json)在首次运行前保存，含11组确有答案与13组缺少答案的材料。两项已知问题作为复现例保留，其余加入明确人物／数值、无关对象、否定、假设、公式、错调查、跨句指代、多子问、完整与不完整比较、因果解释等场景。由同一编码助手编写和核对，不是独立专家评审，也不估计真实用户准确率。

| 标注类别 | 实验结果 |
| --- | --- |
| 确有答案的11组 | 9组放行，2组误拒 |
| 缺少答案的13组 | 6组拦截，7组误放行 |
| 全部24组 | 15组判定与标注一致 |

所有失败的解释：

- E04、E06：被证伪的说法或假设仍包含“由某人发明”，表面关系匹配不能确认断言成立。
- E09：公式中的`1/n`被当作存在数量线索，没有调查数据仍被放行。
- E10：另一份旧调查的数值不能回答当前调查，规则没有验证数据来源。
- E15：展出年份与“发明时间未知”同句出现，年份与所问事件没有正确关联。
- E17、E22：不完整比较和缺少因果解释不在有限句式覆盖内，返回`unverified`并在实验中被放行。
- E05、E16：上下文已明确唯一对象，人物／年份在下一句给出；同句规则误拒了本可通过跨句指代回答的资料。

因此，简单增加“有人名、数字、年份”的规则不足以确认依据。拒绝所有`unverified`也没有经过可用性验证，本轮没有采用该策略。新对照中的失败不会靠继续追加本题专用模式或修改标签抹去。下一候选若采用语义关系验证，应明确输出每个子问题对应的原文、对象与数据来源，对否定、假设、跨句和计算场景重新验证，并保留未知状态；这仍是待评估方案。

## 验证与复现

新增8项行为测试先失败后通过，覆盖识别缺项、显式线索、数字及单位、同句对象、多子问、未覆盖问题保持未知、选定资料范围和不修改原结果。补充零值带单位的回归时先复现失败再修正数字边界。最终全套脚本105项测试通过；这些测试证明工具执行符合定义，不证明实验内容准入通过。

新对照内两道简单方差题人工复核：观测2、6的均值为4、总体方差为4；观测0、2的均值为1、总体方差为1。人物及编码事实均明确是自编合成案例，不作现实事实引用。
