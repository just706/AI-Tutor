# AI、记忆与检索

## 当前模型调用

普通教师使用 DeepSeek 同步调用。上下文包含用户档案、当前用户的有效学习记忆和最近最多 10 条消息；单条用户消息上限 4000 字符。AI 调用成功或失败都会设计为可记录，但主教师事务失败时相关记录可能随事务回滚。

系统提示模型回答学习问题，但没有独立事实核验器。结构化功能通过 JSON 约束和解析器处理，解析失败会走业务异常或降级；因此模型输出仍是外部不稳定依赖。

## 教学编排

意图目前由规则识别为 `chat`、`learn`、`practice`、`path`、`analysis` 或概念困难。教学策略为 `concept_first`、`example_first`、`source_code_first`、`prerequisite_first`、`practice_first`、`debug_misconception`、`summary_review` 等规则结果。策略、步骤和导航动作会被保存，但尚未形成由诊断到检查再到练习的强制状态图。

## 学习会话与掌握度

教师会创建或复用学习会话，状态包括 `CREATED`、`DIAGNOSING`、`PLANNING`、`TEACHING`、`PRACTICE`、`REFLECTION`、`COMPLETED`。意图可以直接改变状态，关闭接口会标记完成。

知识点学习记录保存 0–100 的掌握度、学习状态和学习时间。当前更新采用历史最高掌握度，后续低分不会降低已有值；客观题为 0 或 100，主观题和教学评价依赖模型分数解析。这是工程实现，不是经过校准的教育测量。未来应增加证据数量、间隔复习和可解释状态，而不是单纯展示一个精确百分比。

## 学习记忆

系统支持 `preference`、`difficulty_pattern` 和 `misconception`。只有检测到明确措辞才写入：偏好初始置信度 80、180 天过期；困难模式 70、30 天；误解 60、30 天。重复观察最多加到 95；用户可停用或删除，读取时会将过期记录标记为 `EXPIRED`。当前没有让模型自由写入记忆，主要由规则观察教师对话。

## RAG 当前基线

支持 TXT、Markdown、PDF、DOC、DOCX。文档保存在本地用户目录，解析后按 800 字符切片、120 字符重叠，检索前 4 段（上限 8）。检索按完整英文词和中文相邻双字片段匹配，并统一“下标/索引”“读取/访问”两组表达；中英文连写时分别提取词项。去除常见问句用语后，使用 BM25 词频、文档频率和长度权重排序。`embedding_id` 仍为 `mysql-keyword` 占位标识；没有 embedding、向量库或独立 reranker。

RAG 只读取当前会话明确选择、属于当前用户且处理完成的文档。教材 ID 随会话保存，资料库与主聊天共用问答流程；未选择教材时不能提问，教材删除或不可访问时必须重新选择。结果包括文档 ID、文件名、片段索引和当时的完整片段原文。候选需要达到查询中文词项 40%、英文词项 50% 的覆盖率；某一类词项不存在时不要求该类覆盖率。这是降低弱匹配的工程阈值，不是答案可信度。没有合格片段时直接返回证据不足，不调用模型。即使片段通过阈值，也不能保证它包含完整答案，仍需核对模型回答及引用。

RAG 引用按模型请求中的证据顺序随对应回答保存，两个页面刷新后均可展开；界面区分本次引用序号与教材中的片段位置。保存的是当时原文，不会用重处理后的新片段替换旧证据。历史读取重查教材归属与处理状态，失效时隐藏文件名和原文并明确提示；旧消息没有快照时不补造引用。数组列出的是检索证据，不代表模型的每句回答均已通过引用核验。

RAG 尚未将历史消息用于指代消解；教材绑定只确保连续提问使用同一检索范围，不等于已经理解“它”“那两种”。

2026-09-22 的改动修复了“经常按下标读取元素，应该选哪一种？”因整句匹配而漏检的问题，无需重新上传或切片。任意语义改写、跨片段推理和问答多轮指代仍有局限，应继续用固定测试集量化，再决定是否加入向量检索。

## 个人图谱

个人图谱从文档片段异步提取候选节点、关系和证据。关系类型为 `prerequisite`、`contains`、`related`，证据索引必须属于当前批次；单条非法关系会跳过，整体 JSON 非法则使任务失败。提取完成后必须显式发布，发布会替换该用户该文档的旧图谱，不影响公共知识点图谱或教师回答。

提取按每批 10 段执行，单个文档最多 100 段，分为节点提取和既有节点间的关系提取。超过 100 段的教材保留解析及问答能力，跳过自动图谱提取；需要图谱时先拆分教材。此限制属于图谱调用预算，不是 RAG 上传上限。

## 评测方向

现有评估模块主要统计策略分布、调用成功率、时延和学习会话数据，不等同于教育效果评测。下一步应建立资料内有答案、跨片段、改写、无答案和易混淆问题集，至少分别记录召回、引用支持、拒答、时延和失败率；在此之前不要宣称“真正语义 RAG”或“有效个性化”。

## 候选演进

可以保留 MySQL 业务数据，另加向量存储；Python 单 Agent 可以负责模型编排、混合检索和评测，但 Java 仍负责身份、所有权、事务和写入。LangGraph 适合表达有限教学状态，Multi-Agent 仅用于经过单 Agent 对照实验的复杂任务。它们都是待确认方案。
