# 开发、验证与后续计划

## 本地开发

后端要求 Java 17，前端要求 Node.js 满足 Vite 8 的版本范围。后端默认 8080，前端默认 5173；数据库默认 `localhost:3306/ai_tutor`。配置项见根目录 README 和 `backend/src/main/resources/application.yml`。`run.cmd` 会加载 `.env`，直接运行 Maven 或 jar 时请先设置环境变量。

## 当前验证基线

整理前的本地验证记录：后端离线验证 36 个测试标记中 32 个通过、4 个跳过；前端生产构建通过。测试集中在文档、评估、知识图谱、记忆、学习会话、个人图谱和策略服务，并不覆盖完整浏览器流程、真实模型、并发、数据库故障或所有权限路径。个人图谱有 4 个禁用的旧组合测试，不能把测试数量当作全链路质量证明。

## 已确认限制

1. RAG 已支持完整英文词、中文双字片段、下标/索引等两组表达归一化和 BM25 排序；这仍是词法检索。原始教材中的索引访问问题已加入回归用例，更广泛的中文改写、跨片段和引用支持仍需量化；`embedding_id` 的 `mysql-keyword` 不是向量 embedding。
2. 主教师请求同步调用模型；模型超时会影响一次事务。个人图谱异步任务没有外部队列或启动恢复。
3. 教学策略在回答后决定，未参与同一次回答生成；意图可以跨状态跳转，没有强制的诊断—讲解—检查—练习循环。
4. 客观题评分确定，开放题和教学评价依赖模型分数解析；掌握度使用历史最高值，低分不会回退。
5. AI 路径和临时 AI 练习不持久化为学习计划/题目；学习计划和 Agent 建议主要是规则结果。
6. 上传支持多种文档解析，但当前仍需补充内容类型校验、解析资源限制、提示注入隔离和日志脱敏。文档所有权、随机存储名、删除接口和 5 MB 限制已有基础实现。

## 借鉴批评后的优先级

### 已完成的中文检索修复（2026-09-22）

- 复现用例：“经常按下标读取元素，应该选哪一种？”；旧逻辑把两段中文整句作为关键词，无法找到教材中的“通过索引读取元素”。
- 新检索保留原有文档所有权、已完成状态和选定文档过滤，改进查询拆分、表达归一化、排序和弱匹配过滤；原有数据无需迁移。
- 自动回归覆盖中文改写、中英文连写、对比正文排序、英文大小写、Top-K、无答案和会话归属。运行 `mvnw.cmd -o -Dtest=RagServiceImplTest test` 可单独复核。
- 测试隔离模型和数据库，检索结果与传入模型的证据由真实服务逻辑生成；模型最终回答质量仍需在资料库的“基于资料回答”入口人工复测。
- 更新后需重启后端使新代码生效；已上传的教材可以直接复用。

### P0：安全与交付

- 轮换曾出现在压缩包或日志中的 API Key、数据库密码和 JWT 密钥。
- 对外源码包只保留源码和 `.env.example`，排除 `.env`、`.git`、`node_modules`、`.m2`、`target`、`dist`、日志和 `data/uploads`。
- 生产启动显式要求 `JWT_SECRET`、数据库密码和模型密钥；默认开发密钥只用于本地开发。
- 把 README、实际启动命令、SQL 顺序和已知限制作为唯一入口，历史计划放入归档。

### P1：先证明 RAG 和学习闭环

- 用自己的计算机教材建立小型评测集：资料内答案、跨片段、改写、无答案、易混淆问题各一组。
- 记录 Recall@k、引用支持率、无答案拒答率、首字/总耗时、模型失败率；先得到关键词基线，再比较 embedding、混合检索或 reranker。
- 把状态依据落到答题数量、客观正确率、开放题证据、间隔复习和用户反馈；在此之前页面显示“需要复习/学习中”等解释性状态，谨慎使用精确百分比。
- 将教学流程收敛为有限状态图，代码控制步骤、重试、超时、权限和写入，模型只负责讲解、提问、评价和证据提取。

### P2：再评估 Python 单 Agent

候选职责是模型编排、检索/重排、结构化输出和评测；Java 继续负责 JWT、用户和文档所有权、事务、最终写入及对外 API。先定义稳定的请求/响应和错误契约，Python 不直接访问浏览器、不执行 SQL、不自行修改用户数据。默认路径必须有 Java 原有模型调用或普通 RAG 作为回退。

单 Agent 先限制最多 5 次模型调用、3 个工具步骤、单次 10 秒、总任务 20 秒、失败重试 1 次。只有单 Agent 对照实验显示完成率、时延或成本确实改善，才考虑有限 Multi-Agent；Multi-Agent 失败要能回退。

SSE、Docker Compose、PostgreSQL/pgvector、LangGraph 和公开演示环境属于后续交付目标，不是当前实现。个人图谱已有轮询进度，因此优先把失败、取消和恢复语义稳定下来，再统一流式协议。

## 评测记录建议

每次 AI 请求至少关联 requestId、userId、conversationId、模型名、工具步骤、检索片段、首字时间、总耗时、重试次数、降级标志和错误码；日志不得保存密钥或不必要的原文。教育效果还需要用户完成率、复习后保持率和薄弱点变化等真实数据，不能由技术调用指标替代。
